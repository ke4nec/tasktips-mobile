## §1 设计 §5 九验收用例

| # | 前置 | 操作步骤 | 判定标准 | 记录 |
|---|---|---|---|---|
| 1 | 打开一条 Todo 编辑页 | 断网→改正文→2 秒内再改截止日期→恢复网络 | 最终正文与日期均为最新值；无“已保存”误标旧版本 | ☐ |
| 2a | 手机正在输入同一条 Todo（别松手） | 桌面端改该条正文→手机保存/同步 | 手机输入保留，进入冲突面板；光标不跳、不静默覆盖 | ☐ |
| 2b | 同上 | 桌面端删除该条→手机同步 | 冲突面板标“远端版本为删除”，保留本机/接受删除均有效 | ☐ |
| 3 | 連接 Charles/代理或改代码注入落盘失败（见注） | pull 中落盘失败→杀进程→重启→手动同步 | cursor 未越过失败页；重试后无漏对象、无错误删除 | ☐ |
| 4 | 真机开飞行模式时机 | 有未同步修改时点同步→响应丢失（超时）→恢复网络→再同步 | 日志仅一次 applied；服务端 revision 不跳号（同 requestId） | ☐ |
| 5 | 本机改分类+排序，桌面另改分类+排序 | 手机选项目→预览→确认 | 预览显示两端差异数；冲突走整对象二选一；不宣称自动合并 | ☐ |
| 6 | 目录整树删除中途杀进程 | 重启进回收站 | 状态可解释（全删/全留其一）；已确认墓碑存在（同步后他端一致） | ☐ |
| 7 | 桌面建含未知字段+CRLF+emoji 的 Todo | 手机打开（不编辑）→查同步日志→再编辑保存→桌面重开 | 只读不产生上传；编辑后标题派生与桌面一致 | ☐ |
| 8 | 登录 A→发起同步中途退出登录→登录 B（或重选项目） | 观察 B 的列表与同步状态 | 无 A 的内容/状态串入；旧响应被丢弃 | ☐ |
| 9a | 开启自动同步后关闭 | 观察 15 分钟+改一条本地内容 | 无后台同步；本地改动标“待同步”；手动同步可用 | ☐ |
| 9b | 登录态下离线→退出登录 | 退出→重装/清数据 | 本机内容保留到退出前；新装需重新登录，新设备 ID（设置页/日志可查） | ☐ |

> 注 3：不断代码也可近似验证——同步中途开飞行模式杀进程，再恢复；cursor
> 语义由单测锁定（bootstrap 最终页才启用、pull 整页落盘后推进），真机走一遍
> 确认无崩溃与重复条目即可。

## §2 分享三例（真机）

| # | 前置 | 操作步骤 | 判定 | 记录 |
|---|---|---|---|---|
| S1 冷启动 | 上滑杀掉 App | 浏览器“分享→TaskTips”一条链接 | 只建一条预填 Todo 并自动保存；回到 App 可见 | ☐ |
| S2 热启动 | App 在前台/后台 | 备忘录选一段文字“分享→TaskTips” | 同上，只建一条 | ☐ |
| S3a 重投递 | S1/S2 完成后 | 1 秒内旋转屏幕→切后台→切回 | 不多建条（3 秒同文去重）；间隔 >3 秒同文分享建两条 | ☐ |
| S3b 引导期 | 清除应用数据后**先不打开 App** | 先分享一条→再打开 App 走完引导 | 引导完成后补建该条（FIFO，不吞不逆序） | ☐ |

## §6 自更新（需 GitHub Release + 真机）

> 前置：仓库公开，Release 含 `app-arm64-v8a-release.apk` + `SHA256SUMS.txt`
> （CI 自动上传）。Android 8+ 需“允许安装未知应用”授权。

| # | 前置 | 操作步骤 | 判定 | 记录 |
|---|---|---|---|---|
| U1 | 安装旧版（如上一个 tag 包），自动检查开 | 冷启动→等首帧后 | 有新版弹确认框（版本/大小/更新日志）；无新版/断网静默无弹 | ☐ |
| U2 | U1 弹框后 | 点“立即更新”→授权未知来源（如被问）→返回应用→观察进度→装完 | 授权返回后继续下载；未授权则结束；SHA 不一致报错不装；装完版本号更新 | ☐ |
| U3 | 设置→关闭“启动时自动检查更新”→杀进程重开 | 观察启动 | 不弹更新框；点“检查更新”仍可手动查出新版 | ☐ |
| U4 | 飞行模式下点“检查更新” | 观察提示 | SnackBar 报网络失败，不崩溃；恢复网络后重试成功 | ☐ |
| U5 | 启动检查仍在请求中 | 设置→检查更新；或从其他应用分享文字进入 | 检查只执行一次；请求结束不误关闭分享编辑页、不残留加载框 | ☐ |
| U6 | 正在下载或进度已到 100% 的校验阶段 | 点“取消” | 不调起安装器；本次临时包清理；可重新检查更新 | ☐ |
| U7 | Release 声明含 SHA256SUMS.txt | 模拟该文件超时、损坏、缺少对应 APK 摘要 | 本次检查失败，可去下载页；不得降级为无校验安装 | ☐ |
