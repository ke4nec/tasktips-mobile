## 1. 设计 §5 九验收用例

| # | 场景 | 必须满足的结果 | 状态 |
|---|---|---|---|
| 1 | 正在保存旧快照时继续输入并修改日期 | 最终正文和日期都是最新值，旧回执不清除新修改 | ☐ |
| 2 | 同一条 Todo 在手机输入时被桌面修改或删除 | 保留手机输入并进入冲突处理，不重置光标或静默覆盖 | ☐ |
| 3 | pull 下载成功但本机落盘失败，随后重启 | cursor 未越过失败页，重试后既不漏对象也不错误删除 | ☐ |
| 4 | push 已被服务端接受但响应丢失 | 重启后重试原 requestId，新修改使用新请求（单测已锁逻辑） | ☐ |
| 5 | 本机、远端各有分类和排序，首次接入 | 整对象冲突面板呈现影响，不宣称自动合并 | ☐ |
| 6 | 分类级联、写墓碑或替换 Markdown 中途终止 | 重启后可解释状态，已确认墓碑不丢失（单测已锁落盘顺序） | ☐ |
| 7 | 纯读取含未知字段、CRLF、emoji 的桌面文件 | 不产生无编辑上传；编辑后格式与标题派生一致 | ☐ |
| 8 | 旧账号同步响应晚于退出登录或新账号连接 | 旧响应被丢弃（epoch），内容与状态不串用 | ☐ |
| 9 | 关闭自动同步、离线退出、设备迁移 | 自动任务停止；本机内容保留；新设备不复用旧身份/Token/待提交 | ☐ |

## 3. 系统与无障碍矩阵

- 360dp 窄屏 / 390dp / 200% 字体 / TalkBack 走查今日、列表、分类、回收站、同步页
- 键盘遮挡（编辑页工具栏上移）、手势导航/刘海安全区、系统返回全链路
- 深色/浅色 parity、减少动画开关注走查
- WorkManager 后台 15 分钟任务：关闭自动同步即取消；强制停止后重开恢复检查

## 4. 批次 E/F（需真实服务端）

- 重命名设备 / 撤销其他设备（刷新列表）/ 撤销本机（立即断开清凭据，需重新登录）
- 修改密码（<12 字符拒；成功后其他设备需重新登录）
- 项目历史分页 + kind 筛选；单对象历史；单条正文查看（图片仅显示字节数）
- 创建快照；按快照/按 sequence 发起恢复（含原因校验）；轮询至终态；取消恢复；
  成功后下一轮同步自动走 generation → bootstrap → 预览确认
- 终局失效：服务端撤销设备后，本机下次同步转 disconnected 并清凭据（不再“已连接死循环”）
